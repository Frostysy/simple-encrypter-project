# Simple Encrypter

Programm, mis analüüsib kasutaja esialgset parooli, annab soovitusi ning seejärel krüpteerib antud parooli kindla algoritmi järgi ja salvestab krüpteeritud parooli kindlasse faili. Seejärel loob eraldi võtmete faili ning loob sinna sisse antud paroolile 64 tähemärgi pikkuse "võtme", mida läheb hiljem vaja, et esialgne parool dekrüpteerida.

Projekt lahendab ära probleemi, kus inimene peab oma paroole arvutis ülesse kirjutama (nt: Youtube konto parool -> LaheParool123), mis muudab antud faili lekkiminse korral parooli kuritarvitamise keerulisemaks.

Valisime antud projekti teemaks, sest ühel tiimiliikmel on varasem kogemus paroolide kaotamisega ning paroolid ning nende turavlisus on üldiselt väga aktuaalne teema tänapäeval.
